# 涂鸦机兵 GraffiBots

一款原创的 **第三人称 3D 涂装射击** 联机对战游戏：两队涂鸦机器人用涂料枪抢地盘、抢据点、护送宝物、踢漆弹足球、掠夺电池。浏览器直接玩，最多 4v4，人数不够由 AI 机兵补位。

## 驾驶员

每台机兵都由一位驾驶员操控，驾驶员会坐在机兵的玻璃驾驶舱里。在「机兵整备」里挑选你的驾驶员，空位的 AI 机兵也由这些驾驶员驾驶。

| 驾驶员 | 代号 | 定位 | 擅长武器 |
| --- | --- | --- | --- |
| 凌焰 | 烈焰 | 热血突击手 | 喷罐枪 |
| 白夜 | 霜刃 | 冷面狙击手 | 狙击笔 |
| 苏糖 | 电音 | 元气偶像主播 | 旋转喷管 |
| 雷豹 | 铁拳 | 重装开路者 | 滚刷机 |
| 夜鸢 | 墨鸦 | 神秘涂鸦师 | 泼桶机 |
| 星澜 | 极光 | 天才机兵工程师 | 喷罐枪 |

立绘全部由程序实时绘制成 SVG 矢量图（不依赖任何图片文件，离线可用），会出现在主界面、驾驶员选择、房间列表、开局对阵画面和结算 MVP 中。

## 物理手感

- **有质量的移动**：起步需要加速，松手会滑行一小段，急转会先刹车；双足行走抓地好，滚轮形态在己方涂料上像在冰面上一样滑行、惯性大。
- **涂料改变摩擦力**：敌方涂料又黏又慢，起步和转向都很吃力。
- **跳跃手感**：长按跳得高、短按小跳；走出平台边缘后一小段时间内仍能起跳（土狼时间）；落地前提前按跳会在落地瞬间自动起跳（跳跃缓冲）；下落比上升略快，落地更干脆。
- **贴墙滑行**：斜着撞墙不会卡住，会沿墙滑过去。
- **击退与后坐力**：被子弹打中、被炸弹炸到会被推开（滚轮形态更轻、被推得更远）；狙击笔满蓄力和泼桶机开火有后坐力。
- **机兵动画**：双足步态随真实速度变化，腿会转向移动方向（侧移、倒退都有对应步伐）；上身用弹簧模拟惯性，加速前倾、刹车后仰、转弯侧倾；落地时悬挂压缩回弹、镜头下沉；受击会硬直晃动；滚轮转弯会向内侧倾斜。

## 在手机上玩

手机版支持触屏操作：横过来拿手机，**左半屏是摇杆**（手指放哪里摇杆就出现在哪里），**右半屏滑动转视角**；按住「开火」射击，按住时也能继续滑动瞄准，开火时准星会被附近的敌人轻轻吸住（辅助瞄准）。「跳跃」「滚轮」（点一下切换形态）「💣」炸弹「大招」都在右下角，右上角有暂停、记分板和快捷语音。第一次点屏幕会自动全屏并锁定横屏（安卓 Chrome 支持；iPhone Safari 不支持全屏，建议「添加到主屏幕」后再打开）。手机上默认关闭阴影和描边，保证流畅。

几种在手机上打开的方式：

| 方式 | 适合 | 说明 |
| --- | --- | --- |
| 网页链接（claude.ai） | 马上就玩 | 用手机打开作者分享的网页链接即可，只能和 AI 对战 |
| 电脑开服务器，手机连同一个 WiFi | 和朋友联机 | 电脑上运行 `node server.js`，手机浏览器打开启动时打印的「局域网访问」地址；手机和电脑可以同房间对战。打开后可以「添加到主屏幕」，像 App 一样全屏启动 |
| `涂鸦机兵-单文件版.html` | 安卓手机离线玩 | 把这一个文件发到手机，用文件管理器选择「用 Chrome 打开」。iPhone 的「文件」App 不能运行网页游戏，请用上面两种方式 |
| 放到任意静态网站（如 GitHub Pages） | 长期分享 | 把 `public` 文件夹上传即可，打开后可添加到主屏幕并离线游玩（含离线缓存），联机走 P2P 房间码 |

重新生成单文件版：`node tools/build-single.js`（`--cdn` 生成体积更小、需要联网的网页版）。

## 运行（两种方式任选）

### 方式一：直接双击打开（推荐，不用装任何东西）

1. 解压 zip。
2. 双击 **`开始游戏.html`**（或 `public/index.html`），用新版 Chrome / Edge / Firefox 打开。
3. 「开始游戏 → 创建房间 → 开始对战」就能和 AI 机兵对战，**完全离线可玩**。

**和朋友联机（P2P 房间码）**：
1. 房主创建房间，房间页面显示「联机已开放 ✓」后，把 **4 位房间码** 发给朋友。
2. 朋友同样解压并打开游戏，在「加入房间」输入房间码即可。
3. 双方都需要联网。房主的浏览器就是这一局的服务器，所以**房主要保持游戏页面开着**（最好在前台），房主离开房间会结束这个房间。

说明：联机握手借助免费公共信令服务 PeerJS（只交换连接信息），游戏数据在玩家之间点对点直连。少数公司 / 校园网络会拦截 P2P 直连，这时请换个网络，或用方式二。

### 方式二：运行 Node 服务器

需要 [Node.js](https://nodejs.org/) 18 或更新版本，**不需要安装任何依赖**：

```bash
node server.js
```

然后打开 <http://localhost:3000>。

- 换端口：`PORT=8080 node server.js`（Windows PowerShell：`$env:PORT=8080; node server.js`）
- **同一个 WiFi / 局域网**：服务器启动时会打印「局域网访问」地址（例如 `http://192.168.1.23:3000`），房间页面里也有邀请链接，朋友直接打开即可。第一次运行时 Windows 可能弹出防火墙提示，请允许 Node.js 访问专用网络。
- **不在同一个网络**：用内网穿透工具（如 cloudflared、ngrok、frp）把本机 3000 端口暴露成公网网址，或部署到任意支持 Node.js 和 WebSocket 的云服务器。

## 玩法要点

- 子弹飞出射程后会 **抛物线下坠**，抬高枪口能打得更远；地面和平台顶面都能涂色。
- 场地有矮台（40）、高台（80）和高墙（150）。普通跳跃能上矮台，**滚轮形态跳跃能直接上高台**，高墙无法攀登也不能涂。
- 踩在敌方涂料上会减速并持续掉血；在己方涂料里变滚轮可以隐身偷袭。
- 被击倒 5 秒后在基地重新部署，倒下的位置会被炸开一片敌方涂料。

## 模式

| 模式 | 规则 |
| --- | --- |
| 涂地大战 | 时间结束时涂色面积大的队伍获胜，最后 30 秒隐藏局势 |
| 抢占据点 | 把中央据点涂到 70% 占领，占领期间己方倒计时减少，先归零者胜 |
| 护送宝物 | 抢下中央宝物核心送到敌方一侧终点台，先得 3 分胜（持有者减速但受伤降低） |
| 漆弹足球（原创） | 用子弹、炸弹和身体把大球推进对方球门，先进 5 球胜 |
| 电池掠夺（原创） | 收集地图上的电池送回己方充电站，被击倒会掉落全部电池，先存满 40 个胜 |

武器：喷罐枪、滚刷机、狙击笔、泼桶机、旋转喷管，各自带不同大招（涂装风暴、碾压冲锋、锁定导弹、气泡护盾、极光喷射）。对战获得经验升级，解锁头部涂装。音乐与音效全部由浏览器实时合成，均为原创。

## 项目结构

```
开始游戏.html         双击入口（跳转到 public/index.html）
server.js            Node 服务器：HTTP + 自带 WebSocket
public/core.js       对局核心：30Hz 权威模拟、AI 机兵、房间（Node 服务器和浏览器内置服务器共用）
public/shared.js     服务器与客户端共用的规则、地图、驾驶员数据、3D 物理（移动/跳跃/击退/弹道/涂色）
public/portraits.js  驾驶员立绘（程序化 SVG）
public/sw.js         离线缓存（通过网址打开时生效）
public/manifest.webmanifest  添加到主屏幕用的 App 信息和图标
tools/build-single.js        打包成单个 HTML 文件
public/render3d.js   Three.js 3D 场景、双足机兵与驾驶员模型、程序化动画、涂料贴图、特效
public/client.js     界面、联网（服务器 / 内置服务器 / P2P）、输入、第三人称摄像机、HUD
public/audio.js      程序化音乐与音效
public/vendor/       Three.js r149、PeerJS 1.5.4（均为 MIT 许可）
test/sim.js          无头测试：AI 在 5 种模式 × 3 张地图上各打一局
test/netplay.js      联机测试：两个模拟客户端建房、加入、移动、跳跃、开火、防作弊
test/physics.js      物理测试：加速、滑行、跳跃高度、土狼时间、跳跃缓冲、贴墙滑行、击退
```

运行测试：

```bash
node test/sim.js
```

```bash
node test/netplay.js
```

```bash
node test/physics.js
```
