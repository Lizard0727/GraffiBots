# 涂鸦机兵 GraffiBots

一款原创的 **3D 涂装射击** 联机对战游戏：驾驶员开着涂鸦机兵，用涂料抢地盘、抢据点、护送宝物、踢漆弹足球、掠夺电池。俯视角双摇杆操作，浏览器直接玩，电脑和手机都行，最多 4v4，人数不够由 AI 驾驶员补位。

## 画面与手感

- **开场**：XA 游戏工作室标志 → 涂鸦风加载画面（真实预加载字体、立绘和机体模型），点击可跳过。
- **涂鸦风界面**：每天随机生成的涂鸦砖墙背景，贴纸按钮、胶带海报、拍立得驾驶员卡、撕边模式海报、喷漆「对战」按钮，手绘图标。字体使用站酷庆科黄油体、Bangers、Permanent Marker（均为开源字体，许可证见 `public/fonts/FONTS-LICENSE.txt`）。
- **节奏**：机兵跑得更快，起步和急停几乎即时；滚轮在己方涂料上有惯性。
- **大招演出**：自己放大招时斜切横幅 + 驾驶员立绘 + 大字、镜头冲击、白闪和速度线；队友 / 敌人的大招在屏幕左侧弹出小横幅。每个大招和技能都有专属特效（电磁脉冲的闪电、墨雾的烟、应援的音符、扫描的雷达圈……）。
- **打击感**：枪口火光、命中火花、爆炸火球和烟雾、脚步扬尘、落地尘环、滚轮光迹、冲锋火焰。

## 玩法核心

- **驾驶员 + 机体，自由搭配**：驾驶员带来主动技能（每局 3 次）和被动特性；机体决定生命值、武器、移动速度和大招。11 位驾驶员 × 7 种机体。
- **弹药**：每次攻击消耗 1 格弹药（共 3 格），停火后自动装填；在己方涂料上变成滚轮装填更快。
- **大招**：打中敌人和涂地都会充能，充满后瞄准发动。
- **弹出驾驶员**：机体被摧毁时驾驶员会弹出，拿着手枪继续战斗。活过 6 秒，新机体就**空投在驾驶员脚下**（不用跑回基地）；驾驶员也被击倒才算真正倒下，4 秒后在基地复活。
- **草丛**：躲进草丛敌人就看不见你，除非靠得很近或你开火。脱战 3 秒后快速回血。
- **奖杯之路**：赢一局 +8 🏆，平局 +2，输了 −3，沿途解锁头部涂装。

## 物理手感

- **有质量的移动**：起步需要加速，松手会滑行一小段，急转会先刹车；双足行走抓地好，滚轮形态在己方涂料上像在冰面上一样滑行、惯性大。
- **涂料改变摩擦力**：敌方涂料又黏又慢，起步和转向都很吃力。
- **跳跃手感**：长按跳得高、短按小跳；走出平台边缘后一小段时间内仍能起跳（土狼时间）；落地前提前按跳会在落地瞬间自动起跳（跳跃缓冲）；下落比上升略快，落地更干脆。
- **贴墙滑行**：斜着撞墙不会卡住，会沿墙滑过去。
- **击退与后坐力**：被子弹打中、被炸弹炸到会被推开（滚轮形态更轻、被推得更远）；狙击笔满蓄力和泼桶机开火有后坐力。
- **机兵动画**：双足步态随真实速度变化，腿会转向移动方向（侧移、倒退都有对应步伐）；上身用弹簧模拟惯性，加速前倾、刹车后仰、转弯侧倾；落地时悬挂压缩回弹、镜头下沉；受击会硬直晃动；滚轮转弯会向内侧倾斜。

## 账号和登录

开场动画之后会先进入登录页，有三种身份：

| 身份 | 什么时候用 | 进度存在哪 |
|---|---|---|
| **在线账号** | 用 `node server.js` 开服、通过网址打开时 | 服务器上（`data/accounts.json`），换手机 / 电脑登录进度都在 |
| **本机账号** | 双击 HTML、网页版、安卓 App（没有连上服务器时） | 这台设备的浏览器存储里，一台设备可以有多个账号 |
| **游客** | 点「先不登录，游客试玩」 | 这台设备上，随时可以在「机兵名片」里注册，游客进度会带进新账号 |

- 登录一次之后会记住，下次打开直接进大厅；在「机兵名片」里可以退出 / 切换账号。
- 账号名 2–12 个字（中文、字母、数字、下划线，不分大小写），密码至少 6 位。
- **在线账号**：密码用 scrypt 加盐保存，登录令牌只存哈希，有效 30 天，退出登录即作废；连续输错 5 次密码锁 30 秒。奖杯和经验**由服务器在比赛结束时结算**，客户端只能修改出战配置（驾驶员、机体、已解锁的头部涂装），改本地数据刷不了分。
- **本机账号**：密码加盐后做 4000 轮 SHA-256 再保存，不存明文。它的作用是把同一台设备上不同人的进度分开；能动这台设备浏览器数据的人仍然可以改进度，所以排行、比赛请用在线账号。
- 服务器账号文件的位置可以用环境变量 `GB_ACCOUNTS` 修改；`data/` 已经在 `.gitignore` 里，不会被提交。

## 养成：新手号、宝箱、升级与突破

所有账号都从**新手号**开始（旧版本的进度会重置）：

- **新手教程**：第一次进大厅会邀请你跟教官秦岳走一遍：移动 → 开火 → 涂地 → 跳跃 → 技能 → 大招 → 弹出驾驶员，大约 2 分钟。**可以跳过**（欢迎弹窗里的「跳过教程」，或教程中右上角的「跳过」），跳过也照样给奖励；之后在「玩法」页随时可以重玩。
- **新手宝箱**：完成或跳过教程后获得，必得 5 位常驻驾驶员之一（凌焰、白夜、苏糖、雷豹、夜鸢）。
- **初始机体**：喷罐、滚刷、狙击；其余机体从宝箱开出。
- **货币**：金币（升级、突破）、宝石（买宝箱、兑换）、零件（升级材料）、能量结晶（突破）。全部靠玩获得，不需要花钱：每局结算给金币，每日首胜 +20 宝石，账号升级 +100 金币 +10 宝石，宝箱里也有。
- **宝箱**（概率在游戏里点「概率」可以查看，没有保底；只会开出还没拥有的角色 / 机体，全部拥有后换成金币）：

| 宝箱 | 价格 | 驾驶员 | 机体 | 能量结晶 |
|---|---|---|---|---|
| 补给箱 | 40 宝石 | 2% | 4% | 3% |
| 军用箱 | 100 宝石 | 6% | 10% | 10% |
| 金色空投 | 260 宝石 | 20% | 30% | 35% |
| 角色宝箱 | 180 宝石 | 30%（常驻驾驶员） | — | — |

- **宝石兑换**：10 宝石 → 60 零件，10 宝石 → 120 金币，150 宝石 → 1 能量结晶。
- **升级**：驾驶员 1–11 级，用金币 + 零件升级，每级生命和伤害 +4%（满级 +40%）。
- **突破**：5 级时需要「突破 I」（1 个能量结晶 + 500 金币）才能继续升级，并解锁超载技能；9 级时需要「突破 II」（3 个能量结晶 + 1500 金币），强化被动。
- **公平模式**：组队房间里勾选后，所有人按 7 级、突破 I 计算；快速对战里 AI 的等级跟着你的等级。
- **在线账号**的开箱、购买、兑换、升级都在服务器上执行（随机数也在服务器上），改本地数据没有用。

## 1.7.1 更新 · 断线重连 & 好友申请

## 官网发布到网上（让大家在 Google 上找到）

官网是普通的静态网页，可以放在任何静态网站托管上，不依赖 Claude 或任何服务器。

**生成官网**

```bash
node tools/build-single.js                                   # 离线单文件版（官网的「下载」和「开始游戏」用）
node tools/build-site.js --out _site --downloads --zip graffibots-site.zip
```

`_site/` 就是完整的官网（含下载包、3D 展示台需要的游戏渲染代码、`robots.txt`、`sitemap.xml`、`404.html`），`graffibots-site.zip` 是它的压缩包。

**方式一：GitHub Pages（推荐，免费，推送后自动更新）**

1. 把项目推送到 GitHub 仓库。
2. 仓库 **Settings → Pages → Build and deployment → Source** 选 **GitHub Actions**。
3. 之后每次推送，`.github/workflows/site.yml` 会自动测试、打包（含安卓 APK）并发布，地址是 `https://<用户名>.github.io/<仓库名>/`。

**方式二：Netlify / Cloudflare Pages / 其他静态托管**

注册账号后新建站点，选择「直接上传」，把 `graffibots-site.zip`（或 `_site` 文件夹）拖进去即可。

**官网地址**：在 `site/site.config.json` 的 `url` 填正式地址（留空就用 `public/config.js` 的 `GB_SITE_URL`），并且让 `public/config.js` 的 `GB_SITE_URL` 也是这个地址（游戏靠它检查新版本）。改完重新运行上面的命令。用自己的域名时，在托管平台绑定域名，再把这两个地址都改成新域名。

**让 Google 收录**

1. 打开 [Google Search Console](https://search.google.com/search-console)，添加资源，选「网址前缀」，填官网地址。
2. 验证方式选「HTML 标记」，把 `content="..."` 里的那串验证码填到 `site/site.config.json` 的 `googleVerification`，重新生成并发布官网，再回到 Search Console 点「验证」。
3. 在「站点地图」里提交 `sitemap.xml`。一般几天到几周后就能在 Google 搜到「涂鸦机兵」。

官网已经带好了搜索引擎需要的内容：标题和描述、分享预览图（Open Graph / Twitter）、游戏的结构化数据（schema.org VideoGame）、`robots.txt`、`sitemap.xml`，以及不开 JavaScript 时也能读到的文字版介绍和更新内容。

## 在手机上玩

手机版支持触屏操作：横过来拿手机，**左半屏是摇杆**（手指放哪里摇杆就出现在哪里），**右半屏滑动转视角**；按住「开火」射击，按住时也能继续滑动瞄准，开火时准星会被附近的敌人轻轻吸住（辅助瞄准）。「跳跃」「滚轮」（点一下切换形态）「💣」炸弹「大招」都在右下角，右上角有暂停、记分板和快捷语音。第一次点屏幕会自动全屏并锁定横屏（安卓 Chrome 支持；iPhone Safari 不支持全屏，建议「添加到主屏幕」后再打开）。手机上默认关闭阴影和描边，保证流畅。

| --- | --- | --- |

## 安卓 App（APK）

`android/` 文件夹是一个完整的安卓项目：一个全屏横屏的 App，把游戏文件打包在里面，离线可玩，联机走 P2P 房间码，返回键打开暂停菜单（连按两次退出）。有三种方式得到安装包：

1. **用 GitHub 自动打包（推荐，不用装任何东西）**：把整个文件夹上传到一个 GitHub 仓库，打开仓库的 **Actions → 打包安卓 App → Run workflow**，几分钟后在这次运行页面底部的 **Artifacts** 里下载 `涂鸦机兵-安卓App`，解压得到 `涂鸦机兵-GraffiBots.apk`。
2. **用 Android Studio**：用 Android Studio 打开 `android` 文件夹，菜单 **Build → Build APK(s)**。
3. **命令行**：装好 Android SDK 后，在 `android` 文件夹运行 `gradle assembleRelease`，APK 在 `android/app/build/outputs/apk/release/`。

安装到手机：把 APK 发到手机上点开，按提示允许「安装未知来源应用」即可。默认用调试签名打包；如果想以后更新时直接覆盖安装，在仓库 Settings → Secrets 里设置 `GB_KEYSTORE_B64`（签名文件的 base64）和 `GB_KEYSTORE_PASS`，之后每次都用同一个签名。

iPhone：苹果不允许直接安装 App 文件（需要苹果开发者账号和 Mac 上架或签名），请用 Safari 打开网页版后点「分享 → 添加到主屏幕」，效果接近 App（全屏、有图标）。

## 运行（两种方式任选）

### 方式一：直接双击打开（推荐，不用装任何东西）

1. 解压 zip。
2. 双击 **`开始游戏.html`**（或 `public/index.html`），用新版 Chrome / Edge / Firefox 打开。
3. 在大厅点「对战」就能和 AI 驾驶员开打，**完全离线可玩**；和朋友玩点「组队房间」。

**和朋友联机（P2P 房间码）**：
1. 房主创建房间，房间页面显示「联机已开放 ✓」后，把 **4 位房间码** 发给朋友。
2. 朋友同样解压并打开游戏，在「加入房间」输入房间码即可。
3. 双方都需要联网。房主的浏览器就是这一局的服务器，所以**房主要保持游戏页面开着**（最好在前台），房主离开房间会结束这个房间。

说明：联机握手借助免费公共信令服务 PeerJS（只交换连接信息），游戏数据在玩家之间点对点直连。少数公司 / 校园网络会拦截 P2P 直连，这时请换个网络，或用方式二。

### 方式二：运行 Node 服务器

需要 [Node.js](https://nodejs.org/) 18 或更新版本，**不需要安装任何依赖**：

```bash
node server.js
```

然后打开 <http://localhost:3000>。

- 换端口：`PORT=8080 node server.js`（Windows PowerShell：`$env:PORT=8080; node server.js`）
- **同一个 WiFi / 局域网**：服务器启动时会打印「局域网访问」地址（例如 `http://192.168.1.23:3000`），房间页面里也有邀请链接，朋友直接打开即可。第一次运行时 Windows 可能弹出防火墙提示，请允许 Node.js 访问专用网络。
- **不在同一个网络**：用内网穿透工具（如 cloudflared、ngrok、frp）把本机 3000 端口暴露成公网网址，或部署到任意支持 Node.js 和 WebSocket 的云服务器。

## 玩法要点

- 子弹飞出射程后会抛物线下坠；地面和平台顶面都能涂色。矮台（40）普通跳跃就能上，高台（80）要滚轮跳，高墙不能攀登也不能涂。
- 踩在敌方涂料上会减速并持续掉血；在己方涂料里变滚轮可以隐身偷袭、快速装填。
