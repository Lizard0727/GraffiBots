# 涂鸦机兵 · Godot 电脑版

用 Godot 4.3 重做的涂鸦机兵，现在专注 **Windows 电脑版**。网页版和安卓 APK 暂停更新。

## 内容

- **全部 22 台机体、21 位驾驶员**：攻击方式、特性、大招、充能制技能、被动、超载（R 键）。机体被打爆后驾驶员会弹出来，拿随身武器继续打；场上会空投新机体
- **全部 14 张地图 + 搜刮撤离的超大地图（760×500）**
- **12 种模式**：
  - 涂地大战、抢占据点、护送宝物、漆弹足球、电池掠夺
  - 生死之战、逃亡圈（四队 / 单人）
  - 乐园模式、咒灵讨伐、封印争夺
  - 排位赛：钻石起双方各禁用 2 个，再按 1-2-2-2-1 轮流选人，选的时候中间放驾驶员和机体的 3D 模型，有克制提示
  - **搜刮撤离**：6 支 3 人小队
    - 搜容器（F 键）、网格背包（Tab，可以旋转物品）、安全箱、钥匙房
    - 守卫和 Boss 小队、拉杆电梯、8 个撤离点
    - 带出来的东西进仓库，可以卖掉或兑换；高危行动可以带装备进场，死了就丢
- **开局流程**：匹配对手（5~35 秒）→ 准备确认（偶尔有人不点准备，会重新匹配）→ 排位选人 → 双方阵容 VS 载入 → 观察阶段倒数
  - AI 对手 / 队友有性格（菜鸟、猪玩家、挂机、不错、高手、操作顶尖、大神），有像真人的昵称、头像、头像框和皮肤
  - 对局里 Enter 聊天（Tab 切换 队伍 / 全部），AI 会按性格打招呼、嘚瑟、甩锅、回你的话
  - Esc 暂停（联机时只开菜单）；中途退出按输一局结算
  - 结算有表现评级：MVP / 钻石标 / 黄金标 / 白银标 / 青铜标
- **个人资料**（点左上角的个人卡）：头像（任意已拥有驾驶员或头像皮肤）、头像框（带动画）、称号、昵称、个性签名、生涯战绩、评级统计、3 格展示框和展示框样式
- **好友**：好友码、申请 / 通过、在线状态（通过 `node server.js` 开的游戏服务器，和网页版同一套协议），邀请好友加入你的局域网房间组队
- **新手教程**：第一次进游戏可以先玩 7 步互动教程（移动、开火、涂地、跳跃、技能、大招、弹出驾驶员）再开新手宝箱
- **赛季开场动画**：每个赛季第一次进大厅播一次（通行证页可以重播）；史诗以上的驾驶员皮肤在展台和开局时有专属进场特效
- **养成和经济**：
  - 本地存档在 `user://profile.json`
  - 驾驶员升级和突破、24 个天赋、宝箱和开箱动画
  - 每日 / 每周任务、新手任务线和章节剧情
  - 赛季通行证（免费 / 高级 / 豪华，50 级）、邮件（附件领取和删除）
  - 限时活动（任务、登录奖励、活动商店）、联动兑换
  - 皮肤商店（驾驶员皮肤会换立绘，机体涂装和特效会在展台和对战里生效）
  - 排位段位、夺冠之路和赛季重置
  - 搜刮撤离的交易行（价格每小时浮动，和网页版同一个公式）和本周撤离排行
  - 驾驶员 / 机体页显示克制关系
- **账号（和网页版 / 安卓版通用）**：点左上角的个人卡，或者「设置 → 账号 / 存档」
  - 本机账号的格式和网页版一样：网页版「导出转移码」得到的 `GBACC1.` 码可以直接导入，用原来的密码登录；电脑版导出的码也能导回网页版
  - 注册新账号时会带上现在的进度；没登录就用游客存档（`user://profile.json`）
  - 在线账号：填 `node server.js` 开的服务器地址，登录后把服务器上的进度下载到这台电脑。电脑版单机打的局不会传回服务器
- **局域网联机**：大厅里点「局域网联机」，一人开房，其他人输入房主的 IP 加入，最多 8 人
  - 房主跑权威模拟，其他玩家只发操作，房主每 2 帧广播一次快照
  - 端口是 UDP 24680，第一次开房时要允许防火墙放行
  - 12 种模式都能联机，包括搜刮撤离（容器只同步变化的，搜刮操作由房主执行）
  - 对局里可以聊天
- **大厅**：照原版布局做了个人卡、奖杯、货币、通行证小卡、菜单卡片、二次元立绘 + 3D 机体展台、模式卡、金色对战按钮
- **电脑版设置**：
  - 画面：全屏（F11）、垂直同步、帧率上限、渲染分辨率、画质档位（流畅 / 均衡 / 高 / 极致）
  - 声音：音效和音乐音量
  - 按键：全部可以改
  - 存档：账号管理、重置、版本号
  - 语言：中文 / English（英文用网页版的词典，再加上电脑版自己的界面文字）
  - 手柄：左摇杆移动、右摇杆瞄准、RT 开火、A 跳、B 滚轮、X 技能、Y 大招、LB 超载、Start 暂停
  - 启动时检查 GitHub 上有没有新版本
  - 设置存在 `user://settings.cfg`
- **其他**：
  - 背景音乐：程序离线合成原版的 3 首原创曲（大厅、对战、最后 30 秒）
  - 大招 / 超载会有斜切立绘特写
  - 开场有工作室标志

## 下载

GitHub Releases 里的 `godot-proto` 有 `GraffiBots-Godot-Windows.zip`。解压后双击 `GraffiBots.exe`。

## 开发

- **数据**：`godot/data/game.json` 由 `node tools/export-godot-data.js` 从 `public/shared.js` 和 `public/economy.js` 自动生成，数值和网页版一致
- **美术**：立绘、头像、图标、宝箱图由 `node tools/export-godot-art.js` 渲染到 `godot/art/`
- **代码**：

  | 文件 | 内容 |
  |---|---|
  | `scripts/sim.gd` | 对战模拟，含搜刮撤离和寻路 |
  | `scripts/game.gd` | 画面、镜头、输入、对战流程 |
  | `scripts/lobby.gd` | 大厅和所有子页面 |
  | `scripts/profile.gd` | 存档和经济 |
  | `scripts/net.gd` | 局域网联机 |
  | `scripts/account.gd` | 账号 |
  | `scripts/matchflow.gd` | 匹配、准备、排位选人、VS 载入、观察阶段 |
  | `scripts/bots.gd`、`scripts/chat.gd` | AI 性格 / 昵称 / 外观、对局聊天 |
  | `scripts/social.gd` | 好友和组队邀请 |
  | `scripts/i18n.gd` | 中文 / English |
  | `scripts/thumbs.gd` | 机体 3D 小图 |
  | `scripts/settings.gd` | 设置 |
  | `scripts/music.gd` | 背景音乐 |
  | `scripts/hud.gd` | HUD |
  | `scripts/mode_view.gd` | 模式场景物 |
  | `scripts/models.gd` | 模型 |
  | `scripts/gcard.gd`、`scripts/ui_kit.gd` | UI 组件 |

- **测试**：
  - `godot --headless --path godot --script res://tests/sim_test.gd`：跑所有模式、技能、大招、超载
  - `res://tests/profile_test.gd`：存档、通行证、邮件、皮肤、排位、活动
  - `res://tests/loot_test.gd`：搜刮撤离的整局模拟和性能
  - `res://tests/account_test.gd`：和网页版一样的密码哈希、转移码导入导出；设置 `GB_SERVER=地址` 时还会测在线账号
  - `res://tests/social_test.gd`：两个客户端连同一台服务器互加好友、看在线、发组队邀请（需要 `GB_SERVER`）
- **自动构建**：`.github/workflows/godot.yml`，只出 Windows 版

## 操作

| 按键 | 操作 |
|---|---|
| WASD | 移动 |
| 鼠标 | 瞄准 |
| 左键 | 攻击 |
| Q | 技能 |
| E / 右键 | 大招 |
| R | 超载 |
| Shift | 滚轮形态 |
| 空格 | 跳 |
| F | 搜索 / 互动 |
| Tab | 背包 |
| F11 | 全屏 |
| Enter | 聊天 |
| Esc | 暂停 / 菜单 |

除了 F11 和 Esc，其他按键都可以在设置里改。
