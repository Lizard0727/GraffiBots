# 涂鸦机兵 · Godot 版（移植中）

用 Godot 4.3 重做的涂鸦机兵。现在是第四阶段：

- **全部 22 台机体、21 位驾驶员**：攻击方式、特性、大招、技能（充能制）、被动、机体被打爆后驾驶员弹出 + 随身武器、空投新机体
- **全部 14 张地图**，菜单里可以选地图或随机
- **画面**：卡通三段明暗 + 描边的机兵、双三次过滤 + 噪声边缘的泼溅涂料（两队交界清楚）、霓虹灯条、城市夜景、电脑版 Forward+（SSAO、辉光、ACES 色调、雾）
- **手感**：走路摆腿 / 落地压扁 / 开火后坐、镜头跟随瞄准方向、爆炸震屏、击毁时短暂停顿、大招镜头拉伸、地面瞄准线 / 曲射落点圈、程序合成音效
- **超载技能（R 键 / 手机右边的「超载」按钮）**：21 位驾驶员的超载全部移植，打出伤害充能，用完可以重新充
- **11 种模式**：涂地大战、抢占据点、护送宝物、漆弹足球、电池掠夺、生死之战（三局两胜、一条命）、逃亡圈（四队 / 单人，毒圈 + 空投箱）、乐园模式（花车 + 气球）、咒灵讨伐（4 人打 Boss「百目」）、封印争夺（中立咒灵掉封印石）。每种模式都有场上的东西、AI 目标、顶部比分和结算
- **存档 + 大厅 + 养成**：本地存档（`user://profile.json`）；大厅有对战 / 驾驶员 / 机体 / 宝箱 / 天赋 / 任务六个页面和 3D 展台；新手宝箱、买宝箱（概率公开）、宝石兑换、驾驶员升级（每级生命和伤害 +4%）和突破（突破 I 解锁超载）、24 个天赋（每局带 3 个，效果全部生效）、每日 / 每周任务、对战奖励（经验、奖杯、金币、连胜、每日首胜、账号升级）
- 还没移植：通行证、皮肤、排位、活动、邮件、章节任务线（任务 / 联动 / 通行证 / 特攻队专属的驾驶员和机体暂时拿不到）、搜刮撤离（需要仓库 / 背包 / 交易这一整套经济系统）

- **下载**：GitHub Releases 里的「Godot 版（最新）」——Windows（解压后双击 `GraffiBots.exe`）、安卓 APK、网页版
- **网页版**：官网的 `/godot/` 路径（网页 / 手机用 GL Compatibility 渲染，电脑用 Forward+）
- **数据**：`godot/data/game.json` 由 `node tools/export-godot-data.js` 从 `public/shared.js` 自动生成（数值和网页版完全一致）
- **代码**：`scripts/sim.gd` 对战模拟（移植自 shared.js / core.js）、`scripts/game.gd` 画面 / 特效 / 镜头 / 输入 / 菜单、`scripts/models.gd` 机兵和道具模型、`scripts/sfx.gd` 音效、`scripts/hud.gd` HUD、`shaders/` 涂料 / 卡通 / 描边着色器
- **测试**：`godot --headless --path godot --script res://tests/sim_test.gd`（涂地 4 局 + 其他 10 种模式各 1 局，检查所有技能、大招、超载和每种模式的目标）；`res://tests/profile_test.gd`（存档和养成）
- **自动构建**：`.github/workflows/godot.yml`

操作：WASD 移动 • 鼠标瞄准 • 左键攻击 • Q 技能 • E / 右键大招 • Shift 滚轮 • 空格跳 • R 超载 • Esc 菜单。手机：左摇杆移动、右摇杆瞄准并攻击、右下角按钮。
